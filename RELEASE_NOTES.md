• Peluncuran Resmi Versi Web & PWA: Nikahin kini dapat diakses langsung melalui peramban di https://nikahin-app.pages.dev dengan performa tinggi dan kuota tanpa batas via Cloudflare Pages.
• Dukungan Penuh iPhone (iOS Safari): Nikmati pengalaman aplikasi layar penuh tanpa bilah peramban dengan menambahkan Nikahin ke Layar Utama (Add to Home Screen) menggunakan ikon Warm Champagne beresolusi tinggi.
• Penyimpanan Lokal Cepat WebAssembly (WASM): Mesin database SQLite Drift tetap berjalan offline di peramban menggunakan IndexedDB sehingga rencana pernikahan Anda tetap tersimpan dengan aman.
• Layar Pemuat Cerdas (Branded First-Load Splash): Tampilan transisi pembuka berlatar sampanye dengan logo berdenyut halus saat aplikasi pertama kali dimuat.
• Pengaturan PWA Interaktif: Panduan langkah demi langkah pemasangan aplikasi untuk pengguna iPhone Safari maupun Android Chrome di menu Pengaturan.
• Otomatisasi Rilis Serentak: Alur integrasi CI/CD paralel yang secara otomatis merilis berkas APK Android dan mempublikasikan versi web PWA dalam satu waktu.
