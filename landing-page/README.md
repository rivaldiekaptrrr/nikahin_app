# Nikahin App — Landing Page & Distribusi

Landing page resmi dan portal distribusi aplikasi **Nikahin** (Wedding Planner & Budget Management).

- **Production URL**: [https://getnikahin.my.id](https://getnikahin.my.id)
- **Vercel Mirror**: [https://getnikahin.vercel.app](https://getnikahin.vercel.app)
- **Web App (PWA)**: [https://nikahin-app.pages.dev](https://nikahin-app.pages.dev)
- **GitHub Repository**: [rivaldiekaptrrr/nikahin_app](https://github.com/rivaldiekaptrrr/nikahin_app)

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Icons (`lucide-react`)
- **Animation**: Framer Motion
- **Hosting**: Vercel Edge Network
- **Metadata Source**: GitHub Releases REST API (ISR 5m cache)
