# antislop: Rules for AI Coding Agents

Filter untuk menghentikan agen AI memproduksi antarmuka generic, шаблон template, dan efek visual tanpa tujuan (slop). Desain harus terasa dirancang oleh desainer profesional, memiliki jiwa dan tujuan produk yang otentik.

## Prinsip Utama
1. **The Purpose Test**: Setiap teknik visual (gradien, bayangan, border, kartu, badge) harus memiliki tujuan fungsional, hierarki, atau makna merek yang jelas.
2. **Tanpa Refleks Template AI**:
   - Dilarang menggunakan gradien ungu-biru/neon generik secara otomatis.
   - Dilarang memasukkan semua teks ke dalam bento grid atau nested cards bertumpuk.
   - Dilarang membuat glow neon di setiap sudut elemen.
   - Dilarang membuat dark mode tech-cyber secara default jika produk bukan developer tool.
3. **Keterkaitan Produk Nyata**: Informasi, kartu, dan alur harus merefleksikan alur kerja produk asli, bukan sekadar placeholder visual.
